# أرقام وعناوين — PWA

واجهة التطبيق على GitHub Pages، والبيانات من Google Sheets عبر Apps Script (API).

## الملفات
| الملف | الدور |
|---|---|
| `index.html` / `style.css` / `app.js` | الواجهة |
| `config.js` | **رابط الـ Web App** (الملف الوحيد الذي تعدّله عند تغيّر الرابط) |
| `manifest.webmanifest` + `icons/` | بيانات التثبيت كتطبيق |
| `sw.js` | العمل بدون إنترنت |

## النشر على GitHub Pages
1. ارفع كل الملفات (مع مجلد `icons`) إلى جذر المستودع.
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
3. بعد دقيقة يظهر الرابط: `https://<اسم-الحساب>.github.io/<اسم-المستودع>/`

## التثبيت على الهاتف
- **أندرويد (Chrome):** زر «📲 تثبيت» داخل التطبيق، أو القائمة ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## ملاحظات
- التطبيق يحفظ آخر بيانات في الهاتف فيفتح فورًا ويعمل بدون إنترنت، ثم يحدّث نفسه عند توفر الاتصال.
- بعد تعديل أي ملف في المستودع، افتح التطبيق مرتين لتظهر النسخة الجديدة.
